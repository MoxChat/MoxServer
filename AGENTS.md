# MoxServer Release Repository Rules

1. This repository contains MoxServer release artifacts and deployment documentation only.
2. MoxServer source, MESH-V3, GROUP-V2, specifications, and protocol truth are maintained in the main Mox source repository.
3. Do not add Go source, databases, local caches, real `.env` values, node private keys, or user data.
4. Binary and LPK files must be generated by the main repository release workflow and match the documented version.
5. Deployment documents may describe capabilities but must not redefine mesh, mailbox, routing, group, or retention contracts.
